沈北-新城子同城拼车小程序 UI交互与全景功能需求文档致 UI 设计师：
本项目属于下沉市场/本地生活高频出行工具，针对的是微信群里的“野生拼车”场景（如沈北新城子往返道义）。
核心设计基调： 极致简单、大字号、强对比、抗疲劳。不要做过度的装饰性设计。
场景考虑： 司机经常在户外强光或夜间车内使用，页面对比度要高；操作区域要足够大，防止误触。全局框架设计导航结构： 底部采用双身份融合 Tab：【拼车大厅(乘客找车)】、【我的行程(司乘通用)】、【个人中心】。并在个人中心提供显著的“车主认证/进入司机发车”入口。核心色彩规范（必须严格执行）：即时单（马上走）： 必须用红色、橘色等暖色调，传递紧迫感。预约单（明日/未来）： 必须用蓝色、绿色等冷色调，传递计划性和稳定感。一、 司机端交互流：发车 -> 审核抢座 -> 接客1. 司机首屏：工作台 / 发布行程页页面定位： 司机打开小程序的首屏，核心目标是“3秒极速发单”。核心组件与字段：路线大标签选择： 两大主干道大标签（如：新城子 ↔ 道义商圈），无需设计途径点和金额。发车时间选择（三大金刚键）： 【现在马上走】、【10分钟后】、【自定义预约时间(如明早7点)】。座位设置： 默认显示上次发车座位数，提供大按钮的 + - 操作。底部大按钮： 【确认发布并生成微信分享卡片】（需做呼吸特效或强视觉引导）。2. ★ 核心裂变物料：微信群分享卡片（需单独设计底图）说明：这是本系统拉新的唯一手段，必须抢眼！排版要素（要求高对比度、大字号）：主标题 (最醒目)： 例如： [余2座] 新城子 -> 道义时间标牌 (视觉核心)： 红色底白字的 【马上走】 或 蓝底白字的 【明早 07:30】。底部行动号召： 点击卡片立刻占座，上门接送。3. ★ 核心交互：司机审核抢座（1分钟倒计时浮层）触发场景： 乘客在大厅抢座后，司机端立刻弹出此浮层（即便司机在其他页面）。UI 表现： 底部半屏强弹窗，伴随强烈的语音播报（“收到新的拼车请求，请确认”）。浮层内容：倒计时条： 醒目的 60秒 倒计时UI。审核要素（超大字号）： 该乘客填写的 【上】精确小区门 与 【下】精确地点。动作按钮：绿色大按钮：【顺路，接单】（点击后：总座位-1，该乘客进清单，获取电话）。红色/灰色快捷拒单按钮： 提供 2-3 个巨大的一键拒单按钮，如 【绕路不顺】、【暂无空座】。（点击后：座位释放回大厅，浮层消失）。超时逻辑： 60秒结束未操作，浮层自动收起，系统释放座位，并语音提示司机“超时未响应，已自动跳过”。4. 司机接客看板：接客清单页 (开车时看)顶部状态栏： 行程大标题（如：10:30开往正良）、剩余座位大数字悬浮钮（提供快捷的余座 -1/+1 按钮，应对路边拉客）。乘客列表 (接客清单)： 审核通过的乘客按顺序排列，每个卡片包含：【上】 醒目的具体上车点（如：千禧家园南门）。【下】 醒目的具体下车点（如：辽大北门）。操作区： 巨大的 【拨打电话】 图标、【一键导航】 图标。状态操作： 【确认上车】（乘客卡片变灰折叠）、【踢人退座】。二、 乘客端交互流：看大厅 -> 抢座 -> 等待 -> 成功1. 拼车实时大厅 (首页信息流)顶部筛选： 粗颗粒度的大路线切换（新城子去道义 / 道义回新城子）。行程列表 (信息流卡片)：视觉重点一：【时间标签】 极其醒目的“马上走”或“明日07:30”Tag（强对比色）。视觉重点二：【剩余座位】 动态数字，如果是“满座”则变为灰色不可点。隐私保护： 此时司机车牌号、电话号码均处于隐藏/打码状态。操作： 右侧提供大号的 【抢座】 按钮。2. 精准订座页 (表单输入)输入框： 【精确上车点(具体到小区门)】 与 【精确下车点】。历史地址胶囊： 在输入框下方，自动展示该乘客前几次填写的具体点位，一键点击填入（极大提升体验，V1必做）。按钮： 【确认占座】。3. ★ 核心交互：等待确认与结果反馈 (对应司机的1分钟)抢座后跳转 【等待司机接单】 页：倒计时UI： 页面中心显示 60秒 倒计时。安抚文案（必须一字不差）： “司机正在看路核对您的位置，1分钟内未接单将自动取消，请稍候...”状态分支 1：司机接单（拼车成功）页面状态变为 【拼车成功/等待接驾】。信息解锁：完整展示司机车牌号、车辆颜色。出现巨大的 【一键拨打司机电话】 按钮。状态分支 2：司机拒单 / 60秒超时弹出强提示 Modal 弹窗。文案：“抱歉，司机因路线不顺未能接单。座位已释放，请重新选择车次。”动作：引导返回大厅。三、 特殊组件与空状态 (Empty States)大厅空状态： 不要只写“暂无数据”。配插画并提供大按钮：【当前无车，点此发布您的出行需求】（人找车入口）。司机列表空状态： 提示“今天还没出车哦”，并引导“一键发布常用路线”。
